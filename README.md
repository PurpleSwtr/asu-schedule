# AsuSchedule

Статическое веб-приложение для просмотра расписания занятий МАДИ на Nuxt 3 + Nuxt UI. Разворачивается на GitHub Pages.

## Возможности

- Расписание по неделям: числитель и знаменатель
- Переключение между группами (группы подхватываются автоматически из файлов в `/public`)
- Пары «1 раз в месяц» с ручным расписанием дат
- Просмотр по произвольной дате (календарь)
- Заметки к занятиям с привязкой к дате и паре (хранятся локально)
- Календарь заметок по месяцам
- Свайп для переключения дней недели
- Тёмная/светлая тема и акцентный цвет
- Адаптивный мобильный интерфейс

## Данные

Расписание лежит в `/public/*.json` (по файлу на группу). Новую группу достаточно положить файлом в эту папку — на этапе сборки автоматически генерируется `groups-manifest.json`, и группа появляется в приложении после деплоя.

## Локальный запуск

```bash
npm install
npm run dev   # http://localhost:3000
npm run dev -- --host   # доступ с телефона по Wi-Fi
```

Статическая сборка:

```bash
npm run generate     # результат в .output/public (baseURL = /)
npm run generate:gh  # для GitHub Pages (baseURL = /asu-schedule/)
```

## Сборка данных

Расписание выгружается с сайта МАДИ скриптами из `/utils`:

```bash
python utils/parser_groups.py   # список групп
python utils/parser_sched.py    # расписание группы
```

Полученные JSON-файлы кладутся в `/public`.
