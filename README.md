# AsuSchedule

Статическое веб-приложение для просмотра расписания занятий МАДИ на Nuxt 4 + Nuxt UI. Разворачивается на GitHub Pages.

## Возможности

- Расписание по неделям: числитель и знаменатель
- Переключение между группами (группы подхватываются автоматически из файлов в `/public`)
- Пары «1 раз в месяц» с ручным расписанием дат
- Просмотр по произвольной дате (календарь) с корректным определением недели
- Заметки к занятиям с привязкой к дате и паре (хранятся локально)
- Календарь заметок по месяцам
- Заметки по предметам
- Свайп для переключения дней недели
- Персонализация: светлая/тёмная тема, 11 вариантов тёмной темы, скругление элементов, масштаб текста, плотность интерфейса
- Акцентный цвет: 12 пресетов + свой цвет через удобный пикер
- Подложки чипов: пастельные / тональные / прозрачные (с живым превью в настройках)
- Настраиваемые цвета плашек: лабораторки, лекции, практика, недели
- Экспорт/импорт всех данных в файл (заметки, группа, тема, настройки) - перенос между устройствами
- История изменений и обратная связь внутри приложения
- Адаптивный мобильный интерфейс

## Локальный запуск

```bash
npm install
npm run dev   # http://localhost:3000
npm run dev -- --host   # доступ с телефона по Wi-Fi
```

Статическая сборка:

```bash
npm run generate     # результат в .output/public (baseURL = /)
npm run generate:gh  # для GitHub Pages (baseURL = /asu-schedule/)
```

## Сборка данных

Расписание выгружается с сайта МАДИ скриптами из `/utils`:

```bash
python utils/parser_groups.py   # список групп
python utils/parser_sched.py    # расписание группы
```

Полученные JSON-файлы кладутся в `/public`.
